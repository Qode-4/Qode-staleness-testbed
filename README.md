# Qode-Server 낡음 감지 시험용 포크

> 이 레포는 시험용입니다. 일부러 바꾼 코드가 들어 있으니
> 원본(Qode-4/Qode-Server)에 PR을 보내거나 머지하지 마세요.

## 목적
개발자가 확인한 답의 근거 코드가 바뀌었을 때,
낡음 감지가 `유지 / 위치 갱신 / 재확인 필요`를 맞게 판단하는지 확인한다.

## 브랜치
| 브랜치 | 설명 |
|---|---|
| `base` | 원본 기준 커밋 [1474396cd5ff0f1bf0efc0161bcc62d775c512ac]. 판정을 저장하는 시점 |
| `changed` | base에 시험용 변경을 적용한 상태. 낡음 감지를 실행하는 시점 |

## 시험 방법
1. Qode에서 이 레포를 `base` 브랜치 기준으로 동기화
2. 시험 질문 [N]개를 하고, 답을 "확인됨"으로 판정
3. `changed` 브랜치로 동기화
4. 낡음 감지 결과를 기록
5. 정답표와 비교 (정답표는 이 레포에 없음. PM에게 요청)

## 변경 유형 (어디를 바꿨는지는 적지 않음)
- 근거와 무관한 변경
- 근거 줄 위치만 이동
- 근거 줄의 주석·공백만 변경
- 근거 줄의 값이나 조건 변경
- 이름만 변경 (동작 같음)
- 근거 함수를 다른 파일로 이동
- 근거는 그대로, 부르는 코드만 변경

## 지표
놓침 / 거짓 경보 / 위치 갱신 정확도 / 불필요한 재확인 / 사각지대 놓침
