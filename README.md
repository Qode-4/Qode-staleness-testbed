# 낡음 감지 시험용 포크

> 시험용 포크입니다. 원본(Qode-4/Qode-Server)에 PR을 보내거나 머지하지 마세요.
> .md 파일은 인덱싱 대상이 아니라서 이 문서는 검색 결과에 영향을 주지 않습니다.

## 목적
개발자가 확인한 답의 근거 코드가 바뀌었을 때,
낡음 감지가 `유지 / 위치 갱신 / 재확인 필요`를 맞게 판단하는지 확인한다.

## 브랜치
| 브랜치 | 역할 |
|---|---|
| `develop` | 기준 시점 (원본 1474396). 질문하고 판정을 저장하는 시점 |
| `changed` | develop에 시험용 변경을 적용. 낡음 감지를 실행하는 시점 |

## 시험 절차
1. Qode에서 이 포크를 `develop` 기준으로 동기화
2. 아래 시험 질문을 하고, 각 답을 "확인됨"으로 판정
3. `changed` 기준으로 다시 동기화
4. 질문마다 낡음 감지 결과를 기록
5. `changed` 브랜치의 TESTBED.md에 있는 정답과 비교
